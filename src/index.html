          Send to Xbox FTP over WiFi / LAN

          Nothing queued. Add files, or use Send to Xbox on a game in the Library or a mod in Mod Menus. Unpack detects GOD games, DLC, title updates and XEX games and picks the right folder. Uploads go to a .part file, are renamed when complete and their size is checked on the console. Existing files are never overwritten. Only local network addresses are allowed.

            Connect to your console

            Turn on the FTP server in Aurora (or run XeXMenu / DashLaunch), enter the IP shown on the console and press Connect. Default login: xboxftp / xboxftp.
